# FriendCompass（好友罗盘）

在游戏里随时知道好友在哪里：查询好友所在地区 / 服务器 / 职业，**点一下追踪就自动传送到好友所在的服务器和地图**，同图后悬浮窗箭头实时指向好友位置并显示距离，可在野外大地图（M 键地图）上标记好友位置，**进入副本后自动禁用**。

## 功能

- **一键传送追踪**：点击「追踪」（或 `/fcompass <名字>`）后自动执行：跨服传送（同大区）→ 以太水晶传送至好友所在地图
- **好友列表**：显示所有好友的在线状态、所在地区、服务器、职业，同图好友绿色高亮
- **悬浮罗盘**：同图时显示可拖动的悬浮窗，箭头实时指向好友方向，附名字与距离（米）
- **头顶标记**：在好友角色头顶绘制竖线与菱形标记（屏幕上任意位置可见）
- **地图标记**：打开野外大地图（按 M）时，在地图上标记好友位置与名字
- **跨图提醒**：追踪的好友换图 / 来到你所在的地图 / 上下线时，聊天栏自动提醒（可选提示音）
- **副本禁用**：进入副本（任务）后箭头与标记自动关闭，出本自动恢复

## 安装

1. 从 [Releases](https://github.com/Lotusloyi/FFXIV-Dalamud-Plugins/releases) 下载 `FriendCompass-latest.zip`
2. 解压得到 `FriendCompass.dll` 与 `FriendCompass.json`
3. 在卫月（Dalamud）设置 → 插件 → 开发工具（Developer Settings）→ 添加本地插件（Install from local file），选择 `FriendCompass.dll` 即可

## 使用

- `/fcompass`：打开 / 关闭好友列表窗口
- `/fcompass <名字>`：追踪名字包含该文字的好友并自动传送
- 悬浮罗盘可拖动到任意位置，位置自动记忆
- 不想追踪时传送？取消勾选「追踪时自动传送」，或点追踪后再点「取消传送」

## 传送说明与限制

- **跨服传送**（好友在别的服务器）：自动走游戏内的「跨界传送」流程，需要与好友在**同一大区**，且**不在小队中**（插件会提示退队）
- **跨图传送**：自动选择好友所在地图中花费最低的已调谐以太水晶，正常消耗金币；若该地图没有已调谐的以太水晶（如部分野外），会提示手动前往
- 传送过程中主窗口顶部显示进度，可随时「取消传送」
- 同图后箭头与标记自动出现；好友需在周围约 100 米内（游戏同步范围）才能获取精确位置

## 说明

- 好友所在地区读取自游戏好友列表数据（与游戏内好友列表的「所在地区」一致）
- 地图标记以游戏自身的玩家标记为锚点计算，缩放 / 拖动大地图时会自动跟随
- 显示好友位置属于正常游戏数据读取，但任何第三方插件均有账号风险，请自行斟酌
