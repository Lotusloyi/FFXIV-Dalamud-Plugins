# FriendCompass（好友罗盘）

在游戏里随时知道好友在哪里：查询好友所在地区 / 服务器 / 职业，**点一下追踪就自动传送到好友所在的服务器和地图**，同图后悬浮窗箭头实时指向好友位置并显示距离，可在野外大地图（M 键地图）上标记好友位置，**进入副本后自动禁用**。

## ⚠️ 依赖 Lifestream

**跨服传送功能依赖 [Lifestream](https://github.com/NightmareXIV/Lifestream) 插件**。请在卫月插件列表中搜索并安装 Lifestream 后使用本插件，否则好友在其他服务器时无法进行跨界传送（同服同图的好友定位、箭头、地图标记不受影响）。本插件启动时会自动检测 Lifestream 是否已加载，并在主窗口顶部提示。

## 功能

- **一键传送追踪**：点击「追踪」（或 `/fcompass <名字>`）后自动执行：获取好友位置（自动向服务器刷新）→ 通过 Lifestream 跨界传送（同大区）→ 以太水晶传送至好友所在地图
- **指定分流**：同服同图但没有坐标时，可输入目标分流并点击「前往分流」，与附近以太水晶交互后选择目标编号。没有坐标也可能是客户端尚未同步角色，并不一定是分流不同
- **自动切换分流**：开启「同图未找到时自动切换分流」（默认开）后，记录已尝试的编号并按实际菜单继续。收到好友实时坐标、试完可用编号或遇到失败时暂停；好友列表和区域搜索都不能提供好友的分流号
- **好友列表**：显示好友的在线状态、地区、服务器和职业，默认每 30 秒向服务器刷新，主窗口关闭后仍工作；也可手动刷新
- **悬浮罗盘**：默认直径 160 像素，可调至 280 像素，使用当前相机视图计算方位，显示距离、分流和坐标来源
- **头顶标记与连线**：加粗并描边的竖线、菱形、姓名及距离标签；远处竖线保持最小屏幕高度，视野外或镜头后方显示屏幕边缘方向提示
- **地图标记**：打开当前地区及图层的大地图时，绘制好友标记和姓名，跟随地图纹理节点的拖动、缩放及界面缩放；关闭罗盘不影响地图/头顶标记
- **跨图提醒**：追踪的好友换图或换服时，聊天栏自动提醒
- **上下线提醒**：全部好友的上下线变更默认在聊天栏提醒，无需追踪；初始读取建立基线，不把已有在线好友全部报为新上线
- **远距离坐标**：直接扫描 DR 周边玩家使用的 `CharacterManager.BattleCharas`，并合并完整对象表作为补充，读取原生坐标，无固定 100/400 米限制；优先匹配 ContentId，出生服与完整姓名可补充匹配，同图小队坐标与最近位置仍可补充使用
- **区域玩家名单**：按 DR 的服务器区域搜索方式显示当前地图玩家，并标出是否查到追踪好友；名单没有 XYZ 和分流，界面标注“坐标未同步、分流未确认”
- **分流切换诊断**：从水晶菜单先选择“切换副本区”再选择编号，使用客户端 PublicInstance 确认到达；支持指定分流和日志诊断
- **副本禁用**：进入副本（任务）后箭头与标记自动关闭，出本自动恢复

## 安装

1.3.6.0 通过仓库的 `pluginmaster.json` 提供安装和更新。此前使用本地开发版的用户，请先停用开发版，再通过下方自定义插件源安装，避免两个版本同时加载。

### 方式一：自定义插件源（推荐，无开发警告、可自动更新）

1. 卫月设置 → 插件 → 实验（Experimental）→ 自定义插件仓库（Custom Plugin Repositories）
2. 添加仓库地址：

   ```
   https://raw.githubusercontent.com/Lotusloyi/FFXIV-Dalamud-Plugins/master/pluginmaster.json
   ```

3. 保存后在「可用插件」中搜索 **FriendCompass** 安装即可，之后每次发布新版本卫月会自动提示更新。

### 方式二：本地导入

1. 从 [Releases](https://github.com/Lotusloyi/FFXIV-Dalamud-Plugins/releases) 下载 `FriendCompass-latest.zip`
2. 解压得到 `FriendCompass.dll` 与 `FriendCompass.json`
3. 在卫月设置 → 插件 → 开发工具（Developer Settings）→ 添加本地插件（Install from local file），选择 `FriendCompass.dll`

> 注意：本地导入方式会在插件列表显示「开发警告」（卫月对未托管插件的正常提示），改用方式一的自定义源即可消除。

## 使用

- `/fcompass`：打开 / 关闭好友列表窗口
- `/fcompass <名字>`：追踪名字包含该文字的好友并自动传送
- `/fcompass instance 5`：靠近水晶、关闭其他菜单后，直接请求前往分流 5；也可在窗口输入目标编号
- `/fcompass debug`：把当前分流、坐标来源、原生角色/对象表数量、最远玩家距离、同名角色匹配和区域名单诊断写入卫月日志
- 悬浮罗盘可拖动到任意位置，位置自动记忆
- 不想追踪时传送？取消勾选「追踪时自动传送」，或点追踪后再点「取消传送」

## 传送说明与限制

- **跨服传送**（好友在别的服务器）：通过 Lifestream 插件执行，需要与好友在**同一大区**，且**不在小队中**（Lifestream 会提示退队）
- **跨图传送**：自动选择好友所在地图中花费最低的已调谐以太水晶，正常消耗金币；若该地图没有已调谐的以太水晶（如部分野外），会提示手动前往
- 传送过程中主窗口顶部显示进度，可随时「取消传送」
- 同服同图且有坐标时，悬浮罗盘与标记自动出现。与 DR 周边玩家采用相同的原生角色扫描范围，不按米数过滤；游戏提供该好友的坐标时，即使超过 100 米也可追踪。尚未收到坐标时显示「暂无坐标」，不保证任意地图全图实时定位
- 最近位置默认保留 120 秒，可调至 600 秒，使用黄色并显示位置年龄。它是历史位置，不表示好友仍在那里；离线、换服、切图、换图层或换分流后失效。不在历史位置上绘制角色头顶标记
- 若好友设置了隐藏位置信息，跨界传送仍会执行，但无法确定地图，会给出提示

## 说明

- 好友所在地区读取自游戏好友列表数据（与游戏内好友列表的「所在地区」一致）
- 地图标记按 `AgentMap.SelectedMapId` / `SelectedTerritoryId` 核对区域及图层，并通过实际地图纹理节点计算屏幕位置；不依赖地图标题包含地区名
- 普通好友列表只有地区与服务器，没有全图 XYZ 坐标。本插件和 DR 的公开追踪实现都无法从尚未同步的角色对象中取得实时坐标；要为任意普通好友提供全图实时定位，需要对方主动共享位置等额外数据来源
- DR 的“区域玩家”来自 `InfoProxySearch` 的角色搜索结果，可以列出远处玩家的姓名；该数据没有 XYZ 或分流，不能仅凭名单确认第几分流或绘制精确箭头。默认追踪同图好友时每 60 秒查询一次，查询期间保留原搜索筛选，完成后尽可能恢复；玩家搜索界面打开时暂停自动请求，200 人返回上限会标注 `+`，未查到不能作为好友不在的结论
- 上下线提醒取决于服务器好友列表更新，默认刷新间隔 30 秒，另有两次本地采样确认，不保证瞬时提醒
- 显示好友位置属于正常游戏数据读取，但任何第三方插件均有账号风险，请自行斟酌

## 开发验证

```powershell
dotnet build FriendCompass/FriendCompass.csproj -c Release
dotnet run --project Tests/FriendCompass.Checks/FriendCompass.Checks.csproj -c Release
```

命令从仓库根目录执行。回归检查覆盖方位、屏幕边缘提示、远距离好友匹配、地图坐标/节点变换、上下线变更与缓存隔离，不需要启动游戏。原生角色同步及显示效果还需在当前国服客户端验证。
